# 无双公众号文章下载

> 作者：锤无双 ｜ B站：锤无双 ｜ 交流Q群：**170621740** ｜ 版本：2.0.0
>
> 把你自己的微信公众号**已发表**内容批量备份到本地：HTML + Markdown 双格式，**正式文章与贴图号图文自动分目录存放，各自生成查重索引**。

## 特性

- **双格式落盘**：每篇内容生成 `<日期>_<标题>.html` + `.md`（含 YAML frontmatter）
- **文章 / 贴图分流**：公众号系统会把已发表文章自动二创成「贴图号图文」（标题截断、归入"无双快讯"等合集）。本工具自动识别并分目录存放，避免二创污染你的查重索引
- **双索引**：`公众号文章/公众号文章索引.md` 与 `公众号贴图/公众号贴图索引.md`——日期倒序、每月分组、「发表日期 | 标题 | 主要内容」三列表格，写作选题前扫一眼就知道写过什么
- **双通道抓取**：群发列表（type=9）+「发表记录」接口（appmsgpublish），补齐"仅发布不群发"的内容
- **三种模式**：首次自动全量 / 按上次时间自动增量 / 指定日期
- **零额外依赖**：只用 Node.js 内置能力（Node 21+ 自带 WebSocket）+ Python 标准库，不 `npm install`
- **安全合规**：不写死任何账号凭证；token 仅运行时从你已登录的浏览器会话读取，绝不落盘；不绑定特定公众号

```
<输出根目录>/
├── 公众号文章/                  # 正式图文文章
│   ├── 2026-10-31_标题.html
│   ├── 2026-10-31_标题.md
│   └── 公众号文章索引.md
├── 公众号贴图/                  # 贴图号图文（系统二创）

│   ├── 2026-10-30_标题.md
│   └── 公众号贴图索引.md

```

## 快速开始

```bash
# 1. 启动浏览器（会打开公众号后台，请扫码登录你自己的账号）
node scripts/launch.js

# 2. 登录完成后，执行下载（首次自动全量，之后自动增量）
node scripts/download.js --out ./我的公众号备份

# 3. 生成/更新双索引
python scripts/gen_index.py ./我的公众号备份
```

其他模式：

```bash
node scripts/download.js --out ./我的公众号备份 --mode full                 # 强制全量
node scripts/download.js --out ./我的公众号备份 --mode since --since 2026-06-01  # 指定日期起
```

## 旧版混放库迁移

v1.x 是文章+贴图混放的扁平结构。升级到 v2 后运行一次迁移脚本：

```bash
python scripts/migrate_split.py <旧库目录>
```

自动把散落文件按贴图标记分流到两个子目录、并入旧 `_贴图存档/`、删除旧索引。

## 工作原理

```
launch.js:  探测浏览器(Chrome→Chromium→Edge→Brave→…) → 远程调试端口 9223 → 打开公众号后台
            （启动前清空临时 profile + keepAlive 常驻，防止宿主环境回收 Chrome 子进程）
download.js: CDP 连接 → 运行时读取 token → 群发列表 + 发表记录双通道
             → 三层双向去重（文件名 / 标题前缀 / 含存档目录）
             → 逐篇提取正文 → 日期回填（支持绝对/无年份/相对时间）→ 按贴图标记分流落盘
gen_index.py: 扫描两个子目录 → 各自生成日期倒序查重索引
```

## 常见问题

**Q: 为什么我的"发布"（不群发）的文章没被下载？**
A: v2 已合并「发表记录」接口，仅发布的内容也能抓到。个人号没有 freublish API 权限，走的是后台网页接口。

**Q: 文件日期不对 / 标了今天？**
A: 「发表记录」接口不带时间，日期从文章页 `#publish_time` 回填。极少数页面取不到时间会兜底为当天，可手动改名。

**Q: 浏览器闪退？**
A: 在某些宿主/沙箱环境里，启动器进程退出后 Chrome 会被连带回收。launch.js 已内置 keepAlive 常驻保活，请以后台任务方式运行它。
